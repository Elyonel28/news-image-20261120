# World news, 20 November 2026, in one image

A newspaper-style infographic summing up Friday 20 November 2026:
the UK–EU youth mobility deal agreed at the Brussels summit, Taiwan's
stock-market crash, Prabowo's meeting with Xi, Taiwan flagging
China-linked accounts to Meta, Jakarta's row with Google, the dollar at a
19-month high, and more — drawn with Python/PIL, no AI image generation.

`main.py` copies `entry.png` to `/output/entry.png` (byte-identical).
`build_image.py` is the generator that draws the infographic.
